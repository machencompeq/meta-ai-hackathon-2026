# Meta Global AI Developer Hackathon — 10 天開發計畫

賽程（台灣時間）：10/27 01:00 開幕 → **11/5 10:00 繳交截止** → 11/10 決賽。組別：Indie Dev。主題：Build for Your World。
題目（報名時寫的）：給月光族學生的財務與投資 agent ——「帳單繳得出來嗎？」＋「能安全投資多少、買什麼？」，投資部分由 agent 委員會決策。
設計依據：`初步概念書.md` v0.2（15 人委員會、四層決策、硬規則）。黑客松只做**最小可行版本**，其餘留到之後。

## 1. MVP 範圍（做完就能 demo）

| 做 | 不做（之後再說） |
|---|---|
| 財務官：讀帳本重算結果，算本月可投資金額（照分配順序與預備金 40,000） | 樹莓派 24 小時部署（demo 用筆電／桌機） |
| 風控長：硬規則（先繳帳單、預備金、不賣直到翻正、不加碼槓桿與個股、單一持股上限） | Qlib／RD-Agent 因子挖掘 |
| 研究組 4 人：技術位階、ETF 與存股、籌碼、半導體 → 訊號卡（JSON） | 美股、總經、A50 研究員 |
| 大師組 5 人打分（巴菲特、林區、柏格、達利歐、科斯托蘭尼），用可檢查指標 | 真實下單（永遠不做） |
| 台股總監：串傳導鏈、提 2–3 方案、可推翻但要寫理由；魔鬼代言人 | 完整 1／3／6 個月追蹤（只做回測示範） |
| 輸出一頁決策報告＋決策紀錄；簡單回測 vs 全買 0050 | |

## 2. 模型分工（Meta Model API）

| 角色 | 模型 |
|---|---|
| 台股總監、風控說明、魔鬼代言人 | Muse Spark（推理最強的那個） |
| 研究組訊號卡、大師打分 | 較小、較便宜的 Meta 模型；或本機開源權重（5060 Ti 16GB） |
| 程式加速 | Muse Code（官方 coding agent） |

規則：硬規則與金額計算用 **Python 寫死**，不交給模型；模型只做判讀與說明。

## 4. 隱私（公開 repo 前一定要做）

- Demo 用**假資料或去識別化資料**；不放真實帳本、帳號、身分證、薪資單、截圖。
- API 金鑰放環境變數，不進 repo。
- 專案目錄與記帳系統分開（不要把 `財務\` 整包推上 GitHub）。
